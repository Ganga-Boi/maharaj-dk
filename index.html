DanceMap CPH

Copenhagen's dance scene is fragmented across Facebook, Meetup, and private event pages. DanceMap pulls it all together automatically.

Scraping · AI parsing · Deduplication

From scattered posts to one clean feed

Every day, the system scrapes multiple sources, extracts event details from unstructured text, removes duplicates, and outputs a structured dataset of salsa, bachata, and kizomba events in Copenhagen.

  • Aggregates dance events from multiple sources daily
  • Uses AI parsing to extract date, time, venue, and price from raw text
  • Deduplicates events that appear across multiple sources
  • Outputs structured data ready for display or further processing
